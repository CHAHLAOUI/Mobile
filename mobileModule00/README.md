# Module 00 — Flutter

Chaque exercice est une application Flutter autonome. Depuis le dossier d'un
exercice, lancez `flutter pub get`, puis `flutter run`.

| Sujet | Dossier |
| --- | --- |
| Exercice 00 — affichage de base | `ex00` |
| Exercice 01 — Hello World | `ex01` |
| Exercice 02 — interface calculatrice | `ex02` |
| Exercice 03 — calculatrice fonctionnelle | `calculator_app` |

La calculatrice prend en charge les nombres décimaux et négatifs, la priorité
des multiplications et divisions, l'effacement et la suppression du dernier
caractère. Les expressions invalides, les divisions par zéro et les résultats
non finis affichent `Error` sans interrompre l'application.
